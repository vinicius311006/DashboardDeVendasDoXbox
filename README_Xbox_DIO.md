# 🎮 Dashboard de Vendas do Xbox — Excel

Projeto do desafio **Criando um Dashboard de Vendas do Xbox com Excel**, com foco em organização, análise e visualização de dados.

## Objetivo
Transformar dados de assinaturas em informações visuais para apoiar a análise de receita, planos, add-ons e renovação automática.

## O que foi entregue
- Dashboard executivo com KPIs.
- Filtros por **Subscription Type** e **Auto Renewal**.
- Gráfico de receita por plano.
- Gráfico de assinantes por add-on.
- Gráfico de assinantes por renovação automática.
- Gráfico de evolução mensal da receita.
- Base tabular com 500 registros demonstrativos.
- Aba de análises auxiliares.
- Navegação entre abas.
- README dentro do Excel e em Markdown.

## Estrutura
- `Dashboard_Vendas_Xbox_DIO.xlsx`
- `README_Xbox_DIO.md`

### Abas do Excel
`Dashboard` | `Base_Dados` | `Análises` | `Listas` | `README`

## Dados
A DIO fornece uma base oficial para o desafio. O arquivo externo não ficou acessível neste ambiente, então a entrega contém **500 registros demonstrativos**, estruturados com a lógica do projeto: plano, preço, add-on, desconto, receita, renovação, pagamento, país e idade.

Para reproduzir com a base oficial, substitua os registros da aba `Base_Dados`, mantendo os mesmos cabeçalhos.

## Como visualizar
1. Abra o arquivo no Excel.
2. Entre na aba `Dashboard`.
3. Use os dois filtros no topo.
4. Observe os KPIs e gráficos.
5. Explore a aba `Análises` para conferir os cálculos.

## Tecnologias
Microsoft Excel, fórmulas, tabelas, validação de dados, gráficos e princípios de visualização de dados.
